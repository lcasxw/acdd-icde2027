# Input sources, attribution and scope of distribution

This repository distributes the authors' frozen model outputs, paired evaluation records, source calibration parameters and checkpoints for research reproduction. It contains no EEG waveforms, demographics, medical records, personal identifiers supplied by individual participants, CMT information or internal audit logs. Published study subject codes are retained to match repeated model evaluations of the same participant. Original authors and repositories do not endorse these transformations.

For mixed-source validation files, dataset attribution follows the actual dataset identifier recorded on each row. A source condition appearing on a plot identifies how a model was trained. Each underlying data source retains its own terms. The repository grants no new permissions over upstream recordings or third-party software. The IEEEtran class and bibliography style retain their embedded notices.

## Published checkpoint copies

For each of the 90 Dreyer archives, four directory strings in the configuration metadata were replaced with portable placeholders. Every tensor-storage record, every other ZIP member and every other configuration opcode and argument were checked against the corresponding frozen checkpoint. The public checkpoint file digest differs. Original and public digests, numbers of storages and a storage digest are recorded in [the mapping](artifact/checkpoint_provenance.csv). The storage digest is SHA-256 over sorted storage IDs, each followed by NUL, its buffer SHA-256 and LF. Prediction-based Dreyer replay checks the public file inventory and evaluates the recorded trial probabilities. There was no raw EEG forward pass.
